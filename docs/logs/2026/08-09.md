- **改动**：
  - `flux-core/types/runtime.ts`：`OwnedSurfaceStateBase` + `SurfaceRuntime.open` options 增加 `closeOnSubmit?: boolean`（action-style surface 专用）。
  - `flux-core/types/actions.ts`：`ActionContextSurfaceRuntime.open` options 同步增加。
  - `flux-runtime/surface-runtime.ts`：`open()` 透传 entry；`triggerHook` 在 submit:success 的 onSubmitSuccess nodes dispatch 完成后（含无 nodes 的 skipped 路径），若 `entry.closeOnSubmit` 则 `close(entry.id)`——先刷新（owner 侧 hook）后关闭，与 §6.2 文档化执行顺序一致；submit:error 不关闭。
  - `flux-runtime/action-adapter.ts`：openDialog/openDrawer 把 `args.closeOnSubmit === true` 传入 options。
  - 测试 `surface-close-on-submit.test.ts`（5 例）：closeOnSubmit 提交成功关闭 + hook 先跑 / 未设置不关闭 / submit:error 不关闭 / 无 onSubmitSuccess nodes 也关闭 / openDrawer 透传。既有 `surface-lifecycle-hooks.phase3` 回归通过。
