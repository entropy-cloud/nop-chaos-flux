## Purpose

修复 `packages/flux-react/src/workbench/workbench-shell.tsx:87-116` 运行时拼接 `grid-cols-[...]` 类导致 CSS 无对应规则、workbench body 回落 `grid-cols-1` 单列塌缩（画布 pane 压扁 1232×153 横条、4/7 加号按钮不可点）。

## Current Baseline

- live：graph tab 3 列类侥幸存在（`workbench-shell.test.tsx:286/330-345` 完整字面量恰在扫描面内）；tree tab `grid-cols-[minmax(0,1fr)_22rem]` computed=`1232px`（RECHECK3 实测）。
- `workbenchPanelTrack`（panel-resizer.ts:27-30）取值域固定 {2rem,15rem,22rem} → 类集合有限可静态枚举。

## Goals

- `resolveWorkbenchGridCols` 返回的每一个类在构建 CSS 中都存在对应规则（8 组合全量）。
- 判别测试：`workbench-shell.test.tsx` 改为对**每个组合断言 `getComputedStyle(body).gridTemplateColumns` 轨道数**（jsdom 无布局 → 以"类在产物 CSS 中存在"为准绳：新增单测读取生成 CSS 内容或构建期检查脚本），旧实现（仅模板拼接）必挂。
- playground `#/flow-designer` 三 tab 与 `#/taskflow-designer` tree tab live 复测：canvas 高度恢复、加号按钮 7/7 可点。

## Non-Goals

- 不改各宿主布局结构；不处理簇外宿主（dashboard/scada/report/spreadsheet/word）的 props 对账（归 MA5.3/5.5）。
