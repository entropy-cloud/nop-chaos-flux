# Linear 复刻分析（P4 输入）

> 分析对象：Linear issue tracker（列表/board/peek/命令面板/键盘交互体系）（开源状态：**闭源，风格等价复刻 + 差异声明**）
> 调研日期：2026-08-29（来源见 §8；官方 shortcuts 页 404、medium 原文超时，快捷键以 keycombiner 汇编 + 官方 select-issues 交叉核实，未核实项已标注）
> 上游：R1 §3（交互深度 2 分，flux 两级台阶之一）、C1-2（⌘K 命令面板构想）、C2 **G-B1（⌘K 命令面板原语）/ G-B2（键盘导航框架）**——本应用主对照行；下游：P4a / P4b

## 1. 应用概述

Linear 是键盘优先的 issue tracker，交互体系的三大支柱：① 全局命令面板（⌘K）② chord 序列导航（G-then-X / O-then-X）③ 列表高亮驱动的单键操作流（J/K 移动 → X 多选 → 单键动作）。R1 判定其为 flux"键盘优先交互"台阶的压测对象。

flux 复刻依托：table/crud（列表）、kanban（scheduling，拖拽）、dialog/drawer（peek）、badge、ui `command` 模块基座（无 renderer type）。

## 2. 设计令牌结构

### 2.1 色彩（深色主题为默认；第三方逆向 DESIGN.md 源，复刻前抽样比对）

| 层                  | 值                                                                        | 角色                                                      |
| ------------------- | ------------------------------------------------------------------------- | --------------------------------------------------------- |
| 背景画布            | `#08090a`                                                                 | 最深层                                                    |
| 表面-面板           | `#0f1011`                                                                 | 应用面板、侧边栏                                          |
| 表面-浮层           | `#191a1b`                                                                 | 二级面板、popover/modal                                   |
| 表面-次级           | `#1f2023`                                                                 | 卡片、输入填充、hover 面                                  |
| 正文-1/2/3/4        | `#f7f8f8` / `#d0d6e0` / `#8a8f98` / `#62666d`                             | 标题 / 正文 / 元信息（5.4:1 下限）/ 占位禁用              |
| 品牌紫 / hover / 浅 | `#5e6ad2` / `#828fff` / `#a8b1ff`                                         | 唯一强调色：CTA/链接/焦点环/激活态                        |
| 语义                | success `#27a644`、complete `#10b981`、warning `#f59e0b`、error `#e53935` | 状态 pill = `rgba(色,0.15)` 底 + 同色文字、无描边、全圆角 |
| 边框三档            | `rgba(255,255,255,0.02/0.05/0.08)`                                        | 微分隔/卡片描边/标准分隔                                  |
| 遮罩                | `rgba(0,0,0,0.5)`                                                         | modal backdrop                                            |

浅色主题与深色一一映射（panel→`#ffffff`、hover 紫变深 `#4b57c8`）。elevation = "亮度堆叠"（层越高越亮），投影仅浮层且多层复合。**官方 priority 色值未能核实**——按状态 pill 的 `rgba(主色,0.15)` 模式等效拟定（差异声明记录）。

### 2.2 排版

字体栈 `Inter Variable → SF Pro Display → system-ui…`；代码 `Berkeley Mono → SF Mono → Consolas`（商业字体，**复刻必须替换**，候选 JetBrains Mono/Geist Mono/IBM Plex Mono）。OpenType 特性 `"cv01"+"ss03"` 全局强制（单层 a + 几何字形）；**签名字重 510**（Inter 连续轴，UI 标签/按钮/导航全用，不得以 500/600 替代）。应用侧 body 14px/1.5、small 13px/1.4、caption 12px/1.4、micro 11px/1.3；导航项 14px/510/行高 2.67（凑 40px 触达高）；渐进负字距（72px→-0.022em，≤14px→0）。

### 2.3 间距/圆角/控件尺寸/行密度

间距 4px 刻度（4/8/12/16/24/32…96）；应用网格 max-width 1280px/gutter 24px。圆角层级：2px（checkbox）/ 4px（小工具条）/ **6px（按钮/输入框主圆角）** / 8px（卡片/下拉/toast）/ 12px（modal/面板）/ 9999px（仅状态徽章与头像）。主按钮 padding 8×16px；输入 12×14px；checkbox 16px；switch 36×20；侧边栏 240px；顶栏 64px；头像 20/24/32/40/56。行密度：表头 12px/510/`#62666d`；行 hover `rgba(255,255,255,0.03)`、分隔 0.05 白；单元格 padding 10×16px、正文 14px/400——**36–40px 行高，高密度排版基准（G-E 参照）**。

### 2.4 交互习惯

时序 100–300ms（微交互 100–150ms、状态 200ms、进场 ≤300ms）；缓动 easeOutQuad `cubic-bezier(0.25,0.46,0.45,0.94)`，**禁用弹跳/弹簧**；modal 进场 opacity+scale 0.96→1。行 hover 高亮 + 左缘浮出 checkbox；**hover 按住 Space 即 peek 预览**。按压 active `scale(0.98)` + 加深；focus 双层靛紫环（`0 0 0 2px rgba(94,106,210,.4), 0 0 0 4px rgba(94,106,210,.2)`）。禁用 opacity 0.4 + not-allowed。

### 2.5 图标

自定义线性 + Lucide；默认 16px、描边 1.5px、`currentColor`、直角；刻度 12/14/16/20/24/32。

| 按键         | 行为            | 按键              | 行为                   |

### 4.6 筛选/复制

`F` 筛选；`⇧F` 清最近筛选；`⌥⇧F` 清全部；`⌘.` 复制 issue ID；`⇧⌘.` 复制分支名；`⇧⌘,` 复制 URL；`⇧⌘O` 新建子 issue；`⇧C`/`⇧P` 加入周期/项目。

### 4.7 非键盘交互

看板卡片拖拽跨列/排序（通用行为，产品实测待核对）；行 hover 高亮 + 左缘 checkbox；底部批量操作栏（官方明示）；⌘K/右键双通道动作入口。

## 6. 可复刻边界与差异声明

### 6.1 可复刻

三栏列表骨架、board 列布局、peek 浮层形态、状态 pill 模式（rgba 底+同色字）、行密度与字号档、圆角层级、动效时序窗口（100–300ms easeOut、禁弹簧）、交互模式（chord/多选/批量栏/Display 抽屉）。

### 6.2 差异声明（令牌/布局与原版偏离点）

- 令牌偏离：色值为第三方逆向源（DESIGN.md），非官方 token 表，复刻前抽样比对；priority 色值官方未公开，按 `rgba(主色,0.15)` 模式等效拟定；Inter Variable 字重 510 为变轴专属，静态字重栈近似为 500。
- 布局偏离：Berkeley Mono 商业字体 → 开源等宽替代（字形可见差异）；官网渐变光晕/3D 渲染素材重制或省略。
- 交互偏离：chord/peek/键盘重排为**模拟实现**（G-B2 裁决前无框架原语），e2e 只锁 P4b 范围内声明的模拟子集；看板拖拽细节未经官方文档逐字核实，以产品实测录屏为准。
- 文案与图标：logo/wordmark/favicon 全部替换；营销文案与产品内空态文案全量自拟；Backlog/Todo/In Progress/Done 等通用状态词可保留，自定义图标集用 flux icon 体系重绘；产出界面不得出现"Linear"名称与商标。

## 7. 转 C2 候选

- **富文本描述编辑器**（issue/记录正文 markdown + @mention）：调研确认 flux 无对应原语，C2 未登记；P4a 若复刻详情页描述区将高频撞墙，随 P4b 回写追加。
- **快捷键帮助面板**（`?` 呼出、可搜索）：G-B2 的伴生 UI 件，未单独登记；随 P4b 一并判断是否并入 G-B2 范围。
