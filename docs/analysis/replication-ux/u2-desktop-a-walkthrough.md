## 共性根因（U6 / improvement-analysis 登记建议条目）

1. **裸 HSL 令牌陷阱 × canvas 渲染器 probe 模式**（扩展 U1 F-S1-5 登记）：pivot `resolveDesignTokens` 以 probe div computed backgroundColor 判解析，playground `--background: 40 30% 98%` 分量形态 invalid → 恒回退 light fallback；echarts 侧因 `hsl(${raw})` 包裹消费而幸免。建议登记文本：「improvement-analysis 2026-11-04：canvas 渲染器（pivot resolveDesignTokens）读裸 HSL 分量令牌判 invalid 恒回退 light 主题——深色主题下 pivot/同类 probe 型 canvas 渲染器白底；修复归 U6 令牌格式收敛（playground styles.css / ui theme-tokens 分量值 → `hsl(...)` 整值），渲染器侧无需改动。」
2. **ui ChartContainer aspect-video × 定高 chart**：建议登记文本：「improvement-analysis 2026-11-04：`@nop-chaos/ui` ChartContainer 默认类含 `aspect-video`，与 chart 渲染器固定 height 叠加把 recharts svg 宽钉为 height×16/9，窄面板（dashboard w=4）下右缘裁切；建议 ChartContainer 支持关闭纵横比或缺省 `aspect-auto`（U6 ui 族）。」
3. C2 双模式 primary 色相差异（橙↔蓝）——playground classic 主题令牌本身特性，U6 令牌收敛时一并复核，非缺陷登记。
