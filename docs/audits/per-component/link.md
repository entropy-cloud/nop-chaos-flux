## 发现清单

- [P0-1] **href URL 协议校验缺失**（`link.tsx:24-26` href 直通 `<a href>`）——`javascript:` 等脚本执行 scheme 未拦截；href 可来自表达式绑定（如 `${item.link}` 数据源记录），点击即在当前页面上下文执行脚本——XSS/任意 URL 安全红线面（维度 18）；与 html/markdown sanitize 门禁剥除 javascript: URI（sanitize.ts:19）的安全姿态不一致 → 状态: fixed（test-first：link.test.tsx 新增「drops javascript: hrefs」「keeps safe schemes and relative URLs」2 用例先红（href 直通）后绿；实现：sanitize.ts 新增 `isSafeNavigationUrl` 白名单（http/https/mailto/tel/data: + 无 scheme 相对 URL，大小写不敏感；禁 javascript:/vbscript:/blob:/file:——data: 保留为既有下载链路（crud-views-export.json data:text/csv href，e2e 已测）且 data: 导航为 opaque origin 不触达 opener，红线是当前页面上下文脚本执行）；link.tsx:24-35 不安全 href → undefined（label 仍渲染、不可导航，fail-safe）；link design.md §12 补充 URL 协议校验契约；bug 80 记录）。**同根一致性规则**：同根同型安全缺陷跨族时以已裁定 severity（P0）为准——button 同源缺陷（C1.3 卡 P2-3）据此由 plan-2026-08-06-0529-3 重裁为 P0 并当轮修复，与 link 共用 flux-core `isSafeNavigationUrl` 白名单，行为同构
