## Row Scope Record Expansion + Undefined Variable Monitor — Full Implementation

### Design Decisions

- Row scope payload 最终定为 `{ ...record, $slot: { record, index } }`。
- `record` 和 `index` 不暴露在顶层——`$slot` 是唯一的顶层系统 key，`$` 前缀为系统变量保留、业务字段不允许以 `$` 开头，零碰撞。
- 核心动机：与 form scope 语义一致，使 `visible`、`disabled`、`value` 等属性无论控件在表单还是表行中写法相同。
