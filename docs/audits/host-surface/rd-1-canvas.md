## 发现清单

- [P1-1] **report 侧文档替换不回传 spreadsheet canvas**（`page-renderer.tsx:438-440` stale `spreadsheetSyncSource === lastSynced` guard 阻断 undo/redo/importTemplate 的 replaceDocument 传播；根因：syncSource 只在 spreadsheet→report 方向设置、report 侧替换后不清除）→ 状态: **fixed**（test-first：`page-renderer-shell.test.tsx` undo/redo 传播用例先红后绿 + `designer-core-codec-and-selection.test.ts` syncSource 清除语义用例；修复 = core-dispatch undo/redo/importTemplate 清 syncSource + page-renderer replaceDocument 后以实际 applied clone 更新 lastSynced；bug note 111，plan `2026-08-08-1315-2` Phase 4）
- [P1-2] **React StrictMode 双挂载下 designer core 被 dispose，字段源/选择/预览永久失效**（`page-renderer.tsx` 旧 effect `return () => core.dispose()`——StrictMode 模拟卸载触发 dispose，重挂载后 `initialize()` 因 `disposed` no-op；playground main.tsx 包裹 StrictMode 实测字段源 0）→ 状态: **fixed**（test-first：`__tests__/page-renderer-strict-mode.test.tsx` StrictMode 渲染 + 字段源加载断言先红后绿；修复 = ref-diff 托管模式：仅当 core 被替换时 dispose 旧 core，StrictMode 重挂载保留 live core；bug note 112）
- [P2-1] MA5 P3-09 `as never` 类型绕过（`bridge.ts:75-86`，运行时聚合输入编译期无检查）→ 状态: **fixed**（低成本当场修复：`buildAggregatedRuntimeSummary` 参数改窄接口 `SpreadsheetRuntimeSummaryInput`（host-data.ts:19-26），bridge 传类型安全对象；行为由既有 `bridge.test.ts:123-166` 锁定）
- [P3-1] 字段 drop 到 grid 外静默 no-op 无用户反馈（report-spreadsheet-canvas.tsx:157-213，dropTargetCell 为空则回调不触发）→ 状态: 卡内记录
