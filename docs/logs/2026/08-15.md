### 2026-08-15（追加，scada-demo 布局回归修复）

- **用户验收反馈两个回归**：① 大屏（如 1920x1080）下 scada-demo 画布显示过小看不清；② 页面控制按钮"似乎不起作用"。
- **根因（单一）**：demo schema 误用 `direction: 'col'`，而 `FlexDirection` 类型/`resolveDirection` 只认 `'column'`/`'row'`/`'-reverse'`（`packages/flux-renderers-basic/src/schemas.ts:12`、`flex.tsx:36-43` 白名单过滤），`'col'` 静默降级为 undefined → 外层 flex 实际是 **row** 横排：按钮区(330px)/画布(292px)/图例区挤在一行，画布被压缩到 292x240（leafer `fit: contain` scale≈0.38），按钮区 330px 内 6 组按钮全部换行堆叠且被 stretch 到 264px 高 → 用户点不到/看不清状态变化，误判"开关不起作用"。**注意**：`'col'` 从 3a7ad4db1（首版 demo）起就存在，是继承自早期 amis 习惯的笔误，一直未生效；此前"显示大小对"是因为 `e249da261`（08-09 container-driven sizing）之前画布 DOM 直接取 schema 尺寸 960x520，容器驱动后尺寸由容器决定才暴露。
- **修复**（全部用现有 CSS 类，无新增任意值类）：`scada-demo.tsx` ① 外层 `direction: 'col'` → `'column'`；② 高度链贯通：`main` → `h-screen`、`section` → `h-full flex flex-col min-h-0`、`mt-8` 容器 → `flex-1 min-h-0 flex flex-col`、page → `className: 'flex-1 min-h-0 flex flex-col'` + `bodyClassName: 'flex-1 min-h-0'`、外层 flex → `h-full min-h-0`、canvas → `className: 'flex-1 min-h-0'`（替换渲染器默认 `h-full` 的百分比高度退化——父链全为内容撑高时 `height:100%` 按规范解析失败回退 auto，这是"h-full 无效"的真相，非类缺失）；③ `controlGroup` 内部 flex 同步 `'col'` → `'column'`。同根因顺手修复另 3 个 demo 页：`scada-editor-demo.tsx:17`、`ai-widgets-demo.tsx:50/70`、`dashboard-demo.tsx:150`。
