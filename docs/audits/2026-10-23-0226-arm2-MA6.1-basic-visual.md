## 3. Round C · lab carrier 15 页

官方 capture 58+12 张 + 自研复核 154 张；suspects 0。

### P1-MA6.1-001 · ui `JsonViewer` dark 整块白底黑字——第三方字面色零 dark 守卫（B4/B5，系统级）— **新案**

- **What**：`lab-json-view` dark 下 JsonViewer 保持 `#eee` 白底黑字，与页面 dark 主题断裂。
- **Where**：`packages/ui/src/components/ui/json-viewer.tsx:2`（import `defaultStyles`）+ :25（`style={defaultStyles}` 直传 react-json-view-lite）——第三方 defaultStyles 为 light 字面色；执行者复核：全仓 **零** `.nop-json-viewer`/`.json-viewer` CSS 覆盖（grep 0 命中）。
- **系统级**：组件在 `packages/ui`——所有宿主 dark 模式继承同缺陷（lab-json-view 为走查面实证）。
- **应为之值**：`.nop-json-viewer` 作用域内以 CSS 变量覆写 jsv 类背景/文字色（light/dark 对称），或以 `style` 传主题化 custom styles。
- **定级 P1**：B5 dark 平价契约在 ui 原语层系统性死亡 + 零守卫（无任何 dark 断言/扫描覆盖 json-viewer）。归 MR3 修复队列。

### P2-MA6.1-004（族，face 3/3）· ui Badge 变体低对比（B1）

- `secondary` 紫底蓝字 **3.05:1**（系统性：15 页壳层 chip + antdpro-list 大量徽章）；`warning` 变体亮琥珀字 **1.83:1**（badge/data-source）。与 A/B 两面同根：语义色亮度体系未过 WCAG 下限。

### P2-MA6.1-006（族）· 可点击目标 <24×24（WCAG 2.5.8）

- lab-input-table 数字步进器 **24×16**、排序钮 22×21、collapse 钮 12×21；inline-edit-table 步进器 24×16 ×80（40 组×2）；16px checkbox（visual-quality-r2 既有登记债，引用不重开）。反例（达标）：w4c 行图标 28×28、antdpro 行操作 30×32。

### B4 令牌溯源（Round C 专项）正面结论

- 抽样 15+ 彩色元素：除 json-viewer（P1-001）外**全部溯源到 `--nop-*`/语义令牌**（selected/staged/striped = primary 6–10% color-mix、`--muted`、`--table-striped-bg`）；B6 无裸默认蓝。
- **dark 平价**：v2 对比度扫描 15 页 dark 全 0 命中——推翻预期；唯一例外即 P1-001。

### P3（C 轮归并）：弹层 header 缩进 16px vs body 24px（status dialog 偏差 +40px，不成体系）；drawer footer [Save(primary)][Cancel] 主按钮不在主位（与 crud quick-edit [关闭][保存] 相反——fixture 根因，契约未定义主位序）；"Delete Selected" primary 蓝且空选可点；scope-debug PRE 2 万 px 长行裁切；ndbg-launcher 遮侧栏；badge info 落 secondary 紫而非 `--info` 蓝（B3/B6 变体选错）；Back to Home 3.77:1（并入 P3 对比度清单）。
