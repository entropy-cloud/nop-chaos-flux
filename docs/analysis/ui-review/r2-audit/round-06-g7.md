3. **守卫表达式全量扫描**: grep 19 页全部 `visible`/插值中的 `!== ''`、`!= ''`、`? true : false`、`||` 回退——仅 analytics :698 一处 `!== ''` 守卫（已被种子证伪，见弃报留档 #1）；其余守卫模式均 undefined 安全。

## 弃报留档（本轮核对/证伪过程留档，防后续轮重提）

1. **sundial-analytics 钻取卡首态空壳（证伪，不成立）**: 走查中发现 `sundial-analytics.json:698` 的 `visible: "${chartFocus !== ''}"` 对未初始化变量会因 `customEquals(undefined,'')=false` 而恒为 true，疑似"首屏渲染只有『图表钻取』标题、正文为空串的空壳卡"。**证伪**: `page-data.ts:103-106` 将 `sundial-analytics` 种子化为 `{ chartFocus: '' }` → 首屏求值 `'' !== ''` = false → 卡片正确隐藏。vitest 探针（flux-formula 真实编译器）双测通过后按证伪弃报。该候选若在不知道种子的前提下立案即为误报，特此留档。
2. **workbench 待整理区与已完成区 checkbox 同名 `t7`**（:1461 vs :1544）: 两行分属 `activeView === 'all'` 与 `activeView === 'completed'` 互斥可见板，scope 共享但无同屏冲突，无用户可见影响（R5 #7 同先例）。
