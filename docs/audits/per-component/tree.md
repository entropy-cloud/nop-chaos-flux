- [P2-1] TreeSchema（schemas.ts:229-245）缺 `label`/`title` 类型声明——注册 fields（data-renderer-definitions.ts:386-387）与渲染器消费（tree-renderer.tsx:421 aria-label fallback 链 `label || title || id || 'Tree'`）均有，类型面缺 → 状态: fixed（TreeSchema 补 `label?: string; title?: string`，additive；无行为变更，仅类型契约闭合）
