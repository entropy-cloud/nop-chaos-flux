## Coverage Assessment

**Strong areas** (likely to have good contract coverage):

- Form input renderers (shared `createFieldValidation` + formFieldRules pattern, wrap:true FieldFrame tests)
- Button (propContracts documented, eventContracts, capability contracts)
- Dialog/Drawer (surface handle pattern, shared tests)
- Table/CRUD (multiple test files: data-table.test.tsx, crud-selection-and-features.test.tsx, crud-query-ownership)

**Weak areas** (likely test coverage gaps):

- **diff-view**: Zero integration tests (DV-DISP-04), missing field registration, reactions untested
- **mobile renderers**: OA-14..OA-17 findings indicate shallow test coverage; pull-refresh direction, infinite-scroll error recovery, notice-bar multi-text, swipe-cell geometry untested
- **content display renderers**: cards (selection modes), alert (closable→onClose), mapping/status (fallback logic), carousel (autoPlay/interval), qrcode (level/foreground), markdown/html (sanitize)
- **reaction**: Only on diff-view; `loadAction` as reaction on CRUD; compilation→runtime→renderer reaction handle path untested
- **data-source**: `sendOn`/`initFetch`/`mergeToScope`/`dependsOn` logic lacks integration tests; onSuccess/onError contracts not consumed per H1
- **composite form-advanced**: picker (dialog+search+options), array-editor add/remove/itemRef staleness, combo multi-condition grouping, condition-builder field config — large files with high risk of untested edge cases
- **form**: submitAction chain (initAction→validation→submit→onSubmitSuccess/onSubmitError/onValidateError), submitOnChange debounce, static propagation, cross-field rules (equalsField/notEqualsField), columnCount grid, hiddenFieldPolicy
- **list**: infinite load-more, selection mode transitions, pagination ownership (local/controlled/scope)
- **chart**: lazy-load, resize no-op, onClick/onHover wiring
