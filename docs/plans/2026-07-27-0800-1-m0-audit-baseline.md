## Scope

### In Scope

- arm-index.md 骨架创建（列出 roadmap 阶段、审计报告预期路径、P0/P1 发现摘要）
- 运行全部 `check:audit-*` 脚本并记录输出基线
- 运行 `pnpm audit:deps`、`pnpm audit:knip`、`pnpm audit:mutants`、`pnpm audit:semgrep`、`pnpm audit:react-doctor` 并记录基线
- 运行 `pnpm typecheck && pnpm build && pnpm test && pnpm test:e2e` 确认绿色基线
- 扫描 `docs/` 验证索引完整性
- 将基线写入 arm-index.md 或独立的基线记录文档

### Out Of Scope

- 对审计工具输出结果的分析、分类或裁定
- 任何代码修复或重构
- 审计技能本身的更新或优化
- 绿色基线首次失败时的诊断和修复（若失败则停止并上报）

## Failure Paths

| 场景                                  | 触发                      | 行为                                                        | 可重试 | 用户可见表现                                  |
| ------------------------------------- | ------------------------- | ----------------------------------------------------------- | ------ | --------------------------------------------- |
| check:audit-\* 脚本部分失败           | 某脚本执行报错            | 记录失败 + 继续其他脚本                                     | 是     | 基线记录中标记该项失败状态                    |
| audit:mutants 超时                    | 变异测试运行时间 ≥30 分钟 | 延长 timeout 至 60 分钟；若仍超时则跳过并记录               | 是     | 基线记录中标注 mutants skipped due to timeout |
| audit:semgrep/react-doctor 工具未安装 | 外部工具缺失              | 跳过该工具，使用替代方法（手动 npm install 或记录为不可用） | 是     | 基线记录中标注工具不可用                      |
| pnpm typecheck / build 失败           | 编译错误                  | 立即停止，不上报 green baseline，上报阻滞因素               | 否     | plan blocked，需人工干预                      |
| arm-index.md 格式不规范               | 创建后 review 发现问题    | 按文档规范修正                                              | 是     | 常规修订                                      |
