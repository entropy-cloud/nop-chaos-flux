## 38. gantt 连线删除 X 钮 hover 反复闪烁、无法点击

- **所属组件**: gantt（flux-renderers-scheduling gantt-links）
- **问题描述**: 鼠标悬停 gantt 连线出现红色 X 删除钮后，按钮反复闪烁（实测 1 秒内 15 次挂载/15 次卸载），无法稳定点击。根因：X 条件渲染在连线中点、位于 10px 命中 polyline 的悬停区内，指针落到 X 上触发 polyline mouseleave → X 卸载 → 指针回到 polyline → 重挂载循环。
- **预期行为**: 指针停在连线或 X 上时 X 保持稳定可点，离开链线区域才消失
- **发现方式**: 人工测试（用户报告）
- **状态**: 已修复——hover enter/leave 上移到链线 `<g>` 组（gantt-links.tsx，指针在 polyline 与 X 间移动不再清状态），提交 4e4fde426；判别守护 e2e 见 gantt-bars-and-links.spec.ts "link delete button is stable"（预修复 stash 对照红 15/15 振荡 → 修复后绿）；详见 docs/bugs/101

## 39. 复杂页面所有水平 tab 栏出现幻影垂直滚动条（dynamic-tabs 用户报告）

- **所属组件**: tabs（flux-renderers-basic TabsRenderer + @nop-chaos/ui TabsList）
- **问题描述**: `#/complex-pages/dynamic-tabs` 页 tab 栏（概览/远程数据）右侧出现一条约 30px 的灰色垂直滚动条小块，样式突兀。排查确认为全局缺陷而非单页问题：master-detail（订单明细/操作日志）、notion-database（视图 tab 条，5px 溢出滚动条完全弹出）等所有桌面端水平 tabs 同样存在。根因：TabsTrigger 内建 line-variant 活动态指示条 `after:` 伪元素（`bottom-[-5px] h-0.5`，default variant 下 opacity-0 但仍占据滚动区域）伸出 TabsList padding 盒约 1px；渲染器对水平列表只声明了 `overflow-x-auto`，未声明的 y 轴按 CSS 规则计算为 `auto` → scrollHeight 33 > clientHeight 32 → 每个 tab 栏都物化出一条垂直滚动条（且 tab 栏上滚轮被该 1px 垂直滚动劫持）。
- **预期行为**: 水平 TabsList 只在 x 轴滚动（窄容器横向滚动契约 [G1-R6-视角8-01]），y 轴永不出现滚动条
- **发现方式**: 人工测试（用户报告）
- **状态**: 已修复——TabsRenderer 水平分支（desktop/mobile）显式补 `overflow-y-hidden`（tabs.tsx），垂直 sidebar 列表不受影响，提交 06bc8cb7f；判别守护：包内类契约单测 ×2（水平列表 overflow-x-auto+overflow-y-hidden / 垂直列表无 overflow 类）+ complex-pages-ux-r12.spec.ts "cp9-tabs-y-overflow"（dynamic-tabs/master-detail/notion-database 三页 tablist computed overflow-y 不得为 auto/scroll，修复前红、修复后绿）
