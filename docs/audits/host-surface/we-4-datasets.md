## 发现清单

- [P1-1] **数据集选中路径缺失 → Fields tab 恒空**（`datasetStore.select` renderers 零调用；dataset-panel 行点击仅开编辑对话框；字段插入/复制入口全部依赖 selectedDatasetId）→ 状态: **fixed**（test-first：`dataset-panel-menu.test.tsx`「行点击 → select 断言」先红后绿；修复 = 行点击 `store.select` + 保留编辑对话框；Phase 5 e2e 确认点 = 选中后 Fields tab 展示字段）
- [P1-2] **MoreVertical 死按钮**（dataset-panel.tsx:29-31 handleDatasetMenu 仅 stopPropagation；MA5 P3-07 确认；无编辑/删除入口（core remove() 存在但 UI 不可达））→ 状态: **fixed**（test-first：`dataset-panel-menu.test.tsx` 菜单 Edit/Delete + 确认/取消 4 用例；修复 = DropdownMenu（Edit/Delete）+ 确认 Dialog → `onDeleteDataset`（store.remove + setDirty）；i18n key deleteDataset/deleteDatasetConfirm 双 locale；Phase 5 e2e 确认点 = 删除后数据集消失）
- [P1-3] **列缺 label 数据集持久化后整集被丢弃**（dataset-dialog.tsx:66-88 允许空 label 列保存 vs dataset-model.ts:64-66 validateDataset label required；document-io.ts:440-487 normalizeDataset 恢复时整数据集 fail-closed 丢弃——静默数据丢失）→ 状态: **fixed**（test-first：`dataset-dialog.test.tsx`「空 label 列 save disabled」先红后绿；修复 = canSave 派生 = name + 每列 name/label 非空，按钮/提交同门）
- [P2-1] **数据集面 i18n 硬编码族**（dialog 标题/占位符/类型标签 SQL/API/复数拼接 + field-list Copy title）→ 状态: 登记 DR-13（跨面集中修复）
- [P3-1] 面板行/按钮无稳定 testid（e2e role/text 定位脆弱）→ 状态: 卡内记录（P1-2 修复时菜单按钮已补 `data-testid=dataset-menu-{id}`）
- [P3-2] field-list Copy 按钮语义漂移（title=复制，行为=插入字段）→ 状态: 卡内记录 + 并入 DR-13（i18n 化时裁决语义）
- [P3-3] dataset-dialog handleSave 静默 return（列缺名时无任何错误提示，仅按钮不发）→ 状态: 卡内记录（P1-3 修复后 save disabled 联动，静默路径消除）
