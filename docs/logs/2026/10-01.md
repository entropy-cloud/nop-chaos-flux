### UX-R4 电子表格公式求值与编辑交互（已收口：closure audit approved）

- **根因（实锤）**：spreadsheet-core 无任何公式求值引擎——`applySetCellFormula` 仅把 formula 字符串存进 cell 文档，渲染读 raw value → 公式原文直出（键入与宿主 Set Formula 两条通路皆然）。

  - `packages/spreadsheet-core/src/formula/`（新模块）：`formula-engine.ts`（tokenizer + 递归下降 parser + evaluator；A1 引用/区域/四则幂括号一元负号/比较符/SUM/AVERAGE/MIN/MAX/COUNT/COUNTA/ROUND/ABS；五类错误值 `#CIRC!`/`#NAME?`/`#DIV/0!`/`#REF!`/`#ERROR!`，错误沿依赖传播；聚合对非数值文本跳过——区域含表头文本求和不受污染，数值字符串仍参与）；`recalc-document.ts`（全量重算：memo + visiting 判环、formula 权威存储 + 存量 `=` 前缀 value 防御性升格、值无变化返回原文档引用护栏——per-sheet 身份保持，前面 sheet 变更不翻动后面无变更 sheet）。
