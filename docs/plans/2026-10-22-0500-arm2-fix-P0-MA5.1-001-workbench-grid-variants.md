## Purpose

## Current Baseline

- live：graph tab 3 列类侥幸存在（`workbench-shell.test.tsx` 完整字面量恰在扫描面内）；tree tab `grid-cols-[minmax(0,1fr)_22rem]` computed=`1232px`（RECHECK3 实测）。
- `workbenchPanelTrack`（panel-resizer.ts:27-30）取值域固定 {2rem,15rem,22rem} → 类集合有限可静态枚举（9 个返回串 = 8 模板变体 + `grid-cols-1`）。

## Goals

- `resolveWorkbenchGridCols` 返回的每一个类在 Tailwind 扫描面内存在完整字面量（CSS 规则必生成）。
- 判别测试钉住：变体表与 `workbenchPanelTrack` 组合值程序化等价（rem 漂移即红）+ 全部变体字面量逐字存在于 shell 源码 + 测试文件自身零字面量（反自败）+ `@source` 扫描面钉住。
- live 复测：tree tab computed 多轨道、加号按钮全量可点。

## Non-Goals
