## 发现清单

- [P1-1] **undo/redo/importTemplate 不回传 spreadsheet canvas**（page-renderer.tsx:438-440 stale syncSource guard；根因与修复见 H2 行与 rd-1 卡）→ 状态: **fixed**（test-first：`page-renderer-shell.test.tsx:209-263` 先红后绿 + `designer-core-codec-and-selection.test.ts:172-204`；bug note 111）
- [P1-2] **toolbar 布尔取反模板不解析（`${!designer.canUndo}` 类表达式恒 undefined）→ Undo/Redo disabled 永不生效**（report-designer-toolbar-helpers.ts evalBooleanLike `!` 分支用 NUL 字节标记递归——`\x00${expr.slice(1)}` 经 trim() 后不满足 `${}` 包裹契约直接返回 undefined，整条取反路径为死代码；用户可见：无操作历史时 Undo/Redo 按钮仍可点）→ 状态: **fixed**（test-first：`report-designer-toolbar-helpers.test.ts` evalBooleanLike negation 两用例先红后绿；修复 = `!` 分支直读 `readStatePath(expr.slice(1).trim())` 取反，移除 NUL hack；bug note 113；e2e 确认点 = host spec 初始 Undo disabled 断言）
- [P2-5] undo/redo 面硬编码英文：'Nothing to undo'/'Nothing to redo'/'Unknown command'（core-dispatch.ts:289/:307/:336）+ 'Undo'/'Redo' 标签（toolbar-defaults.ts:7-21）→ 状态: 登记 DR-9（跨面集中修复 i18n 化）
- [P3-1] undo/redo 后 refreshDerivedState 失败 → 文档已回退但返回 ok:false（refresh 失败不回滚文档——回滚语义无补偿）→ 状态: 卡内记录（refresh 仅字段源/inspector 派生，文档一致，风险低）
- [P3-2] 无 Ctrl+Z/Ctrl+Y 快捷键映射（report-designer 无键盘快捷键面）→ 状态: 卡内记录（DR 候选）
- [P3-3] designer undo → replaceDocument 重置 spreadsheet undo/redo 栈 + selection 清空 + activeSheetId 回第一 sheet（spreadsheet 级 undo 历史清空；宿主仅暴露 designer undo 时一致；若宿主同时暴露两套 undo UI 则双栈分歧——潜在分歧维持 watch）→ 状态: 卡内记录
