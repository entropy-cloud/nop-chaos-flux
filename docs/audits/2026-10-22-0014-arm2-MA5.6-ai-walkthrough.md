### P1-MA5.6-001 · `#/ai-conversations` 会话切换永不换装消息（F3 接线漏接，demo schema 侧）— **新案**

- **What**：侧栏高亮（aria-current）正确移动，但聊天区消息列表从不随会话切换/新建而更换——切换两个受管会话显示同一批气泡。
- **Where**：`apps/playground/src/ai/ai-conversations-example.json:49-50`（只绑 `conversationController` + `activeConversationId`，**不绑 `engine`**）；产品契约本体在 `packages/flux-renderers-ai/src/renderers/ai-chat.tsx:169-175`（`engine` prop 外部注入通道，design.md §11.2/§11.5：「host binds `useConversation.activeEngine` via the `engine` prop → ai-chat binds it instead of self-creating」）；`use-conversation.ts:657` 暴露 `activeEngine` 正为此用途；`ai-chat.tsx:314` `activeConversationId` 仅投影 scope/派发事件，不换装消息。
- **Evidence**：气泡计数曲线——新建会话后可见列表不清空（`[2×15]`→`[4×15]`）；两会话间切换同一 4 气泡。demo 自建 detached engine，首条消息落入「无会话」。
- **Net 现状**：unit 层有正确接线守护（`ai-chat-conversation-change.test.tsx` 外部 engine harness、`ai-chat-clone-fallback.test.tsx:87`）；**demo/e2e 层零守护**（21 个 ai spec 无一会话切换换装断言）。
- **应为之值**：demo schema 补 `"engine": "${controller.activeEngine}"` 类绑定（或 ai-conversations 渲染器防御性内联绑定——修复面归 MR 裁决）；用户可见症状 = 旗舰会话路由上「切会话不换聊天」。
- **定级 P1 理由**：默认 demo 配置下核心联动死亡（F3 接线漏接 + 唯一行为网在 mock 接线侧）。归族：独立（demo-wiring 族）。
- **Fix direction**：`ai-conversations-example.json` 补 engine 绑定 + e2e 补「切换→气泡集合变化」断言。
