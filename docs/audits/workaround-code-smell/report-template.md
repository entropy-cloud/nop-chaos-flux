## 严重度标准（prompt §6 原文，评级唯一依据）

- `P0`：临时方案已在制造错误行为，或静默兜底已实际吞掉真实故障。
- `P1`：无出口的转正临时方案；已漂移的重复组；≥3 份同根因重复；根因失传项。
- `P2`：双份大块重复且仍在活跃修改；出口过期；局部症状特判。
- `P3`：观察项（稳定双份重复、轻微 nudge 无注释、低风险遗留注释）。
