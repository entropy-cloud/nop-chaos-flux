## 1. Findings

### P2-MA7.3-001 · spreadsheet 自违反 design.md §10 作用域禁令——57 处裸顶层 `[data-slot='spreadsheet-*']` 选择器 — **新案**

- **What**：spreadsheet 包自己的 design.md §10 规定 data-slot 选择器须收拢在 `.nop-*` 根 marker 下，但 `canvas-styles.css` 存在 57 处**真裸**顶层选择器（如 `[data-slot='spreadsheet-sheet-add']:hover`）——既是自违反，也是 255 基线的最大构成（127 命中中的真债主体）。
- **fix direction**：全部收拢到 `.nop-spreadsheet-root`（或对应根 marker）下——**该单点收口同时塌缩基线大部分命中**（staging 演示于 round-A.md）。归 MR3 队列。
- **定级 P2**：自违反契约 + 全局选择器泄漏风险（跨包同名 data-slot 误伤面），非即时破损。

### P2-MA7.3-002 · gantt drop-indicator 无命名空间 + 零 CSS 规则（marker 漂移）— **新案**

- **What**：gantt 族 5 处 design.md 文档化 vs 实现漂移，其中 `gantt-drop-indicator` 类**无 `nop-`/`data-` 命名空间且零 CSS 规则**（拖放指示线视觉承诺无样式承载）。
- **fix direction**：命名空间化 + 补 CSS（或删除死标记）。归 MR3 队列。
