## Goals

- 4 条 P1 在 live code 上全部收敛，且每条配一条能抓住回归的 focused proof（行为/契约类）。
- `useConversation` 的每一个跨存储边界方法（`delete`/`clearAll`/`switch`）在 **storage 与 no-storage 双模**下都被 focused 测试覆盖，断言「内存态」与「存储副作用」两侧正确，闭合上轮「主路径验证、交叉点漏测」的盲区。

## Failure Paths

| 场景                                 | 触发                                                              | 预期行为                                                                                                                         | 可重试    | 用户可见表现                                                |
| ------------------------------------ | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | --------- | ----------------------------------------------------------- |
| FP-1 删除进行中的会话 + 并发新建     | 流式进行中点删除 X，await abort 期间点「新建 Y」                  | 以 `activeIdRef.current`/函数式更新判定，**不**用陈旧闭包覆盖 Y 的 `setActiveId('Y')`；Y 成为 active                             | 否        | 删除生效且新会话 Y 正常激活；不出现「列表有 Y 但无 active」 |
| FP-2 clearAll 后重载                 | host 接「清空全部」→ `clearAll()` → unmount → 重新 mount          | 存储侧逐条 `deleteConversation(id)`（经 `reportStorageError`），重载后 bootstrap `loadConversations()` **不再 rehydrate** 已清项 | host 决定 | 列表真正清空，「won't die」数据消失                         |
| FP-3 clearAll 单条存储失败           | 某条 `storage.deleteConversation(id)` reject                      | 该条失败经 `reportStorageError({phase:'deleteConversation'})` 回调 host，其余条继续清；内存态仍清空                              | host 决定 | host 可 toast/重试；失败可观测                              |
| FP-4 无 storage 切换往返             | 无 storage：建 A 发消息 → 建 B → 切到 B → 切回 A                  | A 的历史消息**不丢**（驱逐 storage-aware 或快照回灌）；不再重建空 engine                                                         | 否        | 切回 A 仍见先前消息                                         |
| FP-5 citations 含 `<`/`>`/`&` 的文本 | assistant 输出 `5 < 3 and a > b & c` 走内联 citations 渲染        | DOM `textContent` 含 `5 < 3 and a > b & c`；无双编码 `&lt;`/`&gt;`/`&amp;`                                                       | 否        | 正常显示比较/逻辑/链接文本                                  |
| FP-6 citations XSS 不变量            | assistant 输出 `<script>x[1]</script> plain [2]` 走内联 citations | 无 `<script>` 注入；`[1]`/`[2]` citation 仍被解析保留（覆盖 open-audit P2-3 验证点）                                             | 否        | 无脚本执行；citation 卡正常                                 |
