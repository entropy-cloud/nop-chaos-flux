## 1. Findings

### P2-MA7.2-001 · print 模板 `page.background` 未净化 style-attribute 路径（P2，净化覆盖不一致）

- **Where**：`packages/flux-print-core/src/render-html.ts:139`——`background:${template.page.background ?? '#fff'}` 原样内插进 style 属性；**同一行**的 watermark 文本有 `escapeHtml`。执行者源码亲读复核一致。
- **可达性**：引号突破可注入同源 srcdoc / 活文档 innerHTML；**当前信任边界 = schema 作者**（模板为本地编写），今日不可远程触达；**升级条件 = 模板远端分发**。
- **fix direction**：`background` 走 cssSafe 族（同 D15-01 家族）或 escapeHtml+白名单色值；补一条回归测试。归 MR3 队列。

### P2-MA7.2-002 · 三处手写 URL scheme 守卫分歧且均可被 WHATWG 空白规范化绕过（P2，一致性/加固）

- **Where**：`url.ts`、`editor-toolbar-config.ts`、`ai-citations.tsx` 三套独立手写 scheme 校验，均未做前规范化（`\t\r\n` 绕过类）。

- **fix direction**：收敛到共享 `isSafeNavigationUrl` + 前规范化。归 MR3 队列。
