## 发现清单

- [P1-1] **findResultShape 契约漂移（声明即契约，lesson 08 类别）**——`spreadsheet-manifest-shapes.ts:133-146` 声明 find/findNext result = `{cell: cellRefShape, value}`，实际 `FindResult`（commands-style.ts:121-129 + findInDocument 返回 search-operations.ts:89-98）= `{sheetId, address, row, col, value, matchStart, matchEnd}`——host contract 公共结果面声明与实现不一致（当前 action-provider 不校验 result 故无运行时错误，但声明面错误）→ 状态: **fixed**（`spreadsheet-manifest-shapes.ts:133-146` findResultShape 对齐 FindResult 字段；复现测试 `spreadsheet-manifest.test.ts` find result shape 块，bug note 110，plan Phase 4）
- [P2-1] 查找结果消息硬编码英文 3 处用户可见（`use-find-replace.ts:25/:30/:61` 'Found at ...'/'Not found'/'Replaced N occurrences'）→ 状态: **DR-6 路由**（`round2-dr-adjudication.md` §1，Phase 4 登记）
- [P3-1] FindNext 无独立 UI 按钮（面板 Find 按钮每次从头找，无 next 续扫/循环；findNext 命令仅 host contract 可达）→ 状态: 卡内记录（能力缺口）
- [P3-2] find-results 结果行无 role=status/aria-live（读屏不播报查找结果）→ 状态: 卡内记录（a11y 增强候选）
- [P3-3] replace/replaceAll 无结果路径 + findNext 续扫无直接单测 → 状态: 卡内记录（随 P1-1 复现测试补覆盖）
