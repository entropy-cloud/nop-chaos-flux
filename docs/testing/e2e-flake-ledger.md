## States

`OPEN` → `ATTRIBUTED(timing-defect | not-reproduced(warm-run) | contention | cold-start)` → `CLOSED(fixed | sanctioned-skip | watch-only | retry-absorbed)`.

- `timing-defect`: a single-worker `--repeat-each` run reproduces a non-deterministic failure (ratio recorded).
- `not-reproduced(warm-run)`: all repeats green on an already-running web server. This does **not** refute a cold-start family (the first-entry window is never exercised) and does **not** by itself prove contention.
- `contention`: three pieces of evidence — red in a full parallel run, green in single-spec isolation, green across repeats.
- `cold-start`: positive only through a fresh-server probe (restart the web server, then run the first-entry smoke once); otherwise the QA.7 family tag stays as history.
- Closure exits: `fixed` (test now deterministic; entry must keep naming an existing test), `sanctioned-skip` (registered in the ledger's skip list in `docs/testing/e2e-baseline-ledger.md`), `watch-only` (title tag + `E2E_EXCLUDE_WATCH_ONLY=1` clean-run exit), `retry-absorbed` (playwright `retries: 1` absorbs it; re-observe when the retry budget changes).

The QA.7 family tag is a secondary label carried by every migrated entry; a single repeat matrix never overwrites it.
