- **描述**：I11.2 钳制兜底（handlePluginZoom）与引擎命令路径（applyViewportState，scada-engine.ts:311）均以视口原点世界点为锚，两路径自洽且保持 M-3 符号约定（`zoomLayer.x = -viewport.x*scale`，测试 scada-engine.test.ts:297-313 断言正确）——**功能无缺陷**。但 design-engine.md §4.4 核对结论块写「以视口中心为锚」，与实际行为（原点锚）不符；锚点选择影响重钳制时屏幕固定点（原点 vs 中心），为 UX 细节。
- **建议改法**：二选一——① 设计文档 :123 改「以视口原点世界点为锚」（与 M-3 推导 §5 口径一致）；② 实现改为视口中心锚（`viewportToWorld(this.viewport, { x: size.width/2, y: size.height/2 })`）并使 applyViewportState 与同步路径同锚。倾向①（原点锚与命令路径/M-3 推导天然一致，改动最小）。
- **验证方式**：文档核对 + 既有钳制单测保持绿；I14 真实浏览器 wheel 越界复测作最终确认。

#### m-B：`applyInitialViewport` 于每次 config 同步重执行（含 diff 增量与绑定域重建后的二次执行）

- **落点**：代码 `use-scada-config-sync.ts:110`（同步 effect 尾部无条件 `applyInitialViewport(runtime, config, latest.current.viewport)`）；设计语义 `design-renderer.md` §4.1:78（viewport「**初始**视口策略」）。
- **描述**：config 每次同步（含同版本 diff 增量：点表/图元增删变更）都重应用 fit/center/fill——偏离「初始」语义，可能重置用户在画布上的平移/缩放；且当 reloadBindings 重建 runtime（setRuntime 新对象触发 effect 重跑，deps 含 runtime）时，同一 config 更新内视口策略被执行**两次**。影响面：仅 config 变化场景（设计明示 config 变化频率低，design-renderer.md §12.3:322），默认无 viewport policy 时 no-op（:44 守卫）；非契约破坏，属行为边界不精确。
- **建议改法**：① 仅 full（reset）策略路径应用初始视口（diff 增量不重应用）；② 或经 ref 记录「已应用 policy 的 config」防重复；③ 或文档明示「viewport 策略在每次 config 同步时重新帧定」（I13.1 演示页确认期望行为后回写）。
- **验证方式**：新增组件测试——同版本 config 变更（点表值变化）后断言 getViewport 未被重置；I13.1 真实页面人工核对。

#### m-C：交互覆盖物几何依赖节点 x/y/width/height，无宽高语义图元 hover 覆盖物为 0 尺寸

- **落点**：代码 `interaction-overlay.ts:46-61`（highlight 读 node.x/y/width/height/rotation 构造覆盖 Rect）。
- **描述**：矩形/复合图元（device/instrument 等有 defaults 尺寸，device-symbols.test.ts:120 断言缺省尺寸回退）覆盖物正确；但 `scada-line`/`scada-arrow`/`scada-polygon` 等无 width/height 语义的基础图元，覆盖物为 0×0 不可见（hover 高亮失效但事件仍派发）。I11.2 验证页与单测均只用 rect 类图元，此边界未被覆盖。
- **建议改法**：① I13.1 scada-demo 引入非矩形图元 hover 场景确认影响；② 覆盖物几何按节点 bounds（getBounds 或子节点包围盒）兜底；③ 或文档明示覆盖物当前支持矩形语义图元（I15.1 e2e 覆盖线/多边形 hover 断言）。
- **验证方式**：I13.1 真实浏览器 + I15.1 e2e（测试句柄读 sky 层覆盖物 rect 尺寸断言）。
