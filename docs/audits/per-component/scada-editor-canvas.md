## 发现清单

- [P1-1] `ScadaEditorCanvasSchema` 缺 `loading`/`empty`/`error` region 声明（`editor/schemas.ts:19-42` 消费 `props.regions.loading/empty/error` at `scada-editor-canvas.tsx:210` 但 interface 未声明）——schema 类型与 definition fields 漂移 → 状态: **fixed**（补齐 `loading?`/`empty?`/`error?: SchemaInput` + import SchemaInput）
- [P2-1] editor renderer definition 缺 `propContracts`/`eventContracts`（`renderer-definitions.ts:17-49`）——工具链无法发现 6 prop + 7 event → 状态: **fixed**（补齐 7 propContracts + 7 eventContracts 含 payload shape）
- [P2-2] canvas 交互面缺 `role`/`aria-label`（`scada-editor-canvas.tsx:262-270`）——有 tabIndex 无 role，读屏无语义 → 状态: **fixed**（`role="application"` + `aria-label={t('industrial.scada.editor.canvasLabel')}`）
- [P2-3] `props.meta.disabled` 未响应（`scada-editor-canvas.tsx` 全文无 disabled 消费）——host 设 disabled 时编辑器仍可操作 → 状态: **fixed**（`aria-disabled` + `inert` + drop/keyboard guard）
- [P2-4]（shared）error code `invalid-config` vs `config-invalid` 语义混淆（`scada-editor-canvas.tsx:42` parseAndValidateConfig 用 invalid-config，runtime scada-canvas.tsx:46 用 config-invalid）——两个码语义不同（invalid-config=命令句柄失败不升级；config-invalid=校验失败升级），editor 误用 → 状态: **fixed**（统一为 config-invalid）
- [P3-1] palette `title={def.type}` 用技术标识符（`editor-palette.tsx:51`）——非 i18n 文案，应使用 displayName → 状态: **fixed**（改为 `def.name`）
