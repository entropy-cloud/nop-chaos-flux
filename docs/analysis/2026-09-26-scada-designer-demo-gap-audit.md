**编辑器 mission 实现层已收口，demo 页落后于实现面——但落后形式与 backlog §8 的描述有出入，需先校正一处事实**：

- Roadmap E0–E11 全部 `done`：E0 spike（2026-08-05）→ E1 选型 gate + 包络（08-06）→ E2 六份设计 + E3 设计 gate（08-06）→ E4 包基建 → E5 M1 MVP → E6 M1 gate（08-07）→ E7 M2 连线 + undo-redo → E8 M2 gate → E9 M3 工具箱 + E9.2 benchmark 复测 → E10 M3 gate + mission 收尾（08-07）→ E11 逐组件审计（audit card `docs/audits/per-component/scada-editor-canvas.md` 状态 `closed`，2026-08-08）。post-remediation 两条 plan（`2026-08-07-1835-1/-2`）+ 两轮 P2 收口 plan（`2026-08-08-0900-1/-2`）均 full-green。
- **关键事实校正**：backlog §8 称 demo「仍停留在 M1 能力面（palette 24 图元 + 画布 + inspector + save/load）」。**这一描述低估了 demo 的实际能力面**——`scada-editor-canvas` renderer 对 palette/inspector/toolbox/statusBar 四个 region 均有**内置默认面板 fallback**（`scada-editor-canvas.tsx:268-271` toolbox、`:276` palette、`:402-404` inspector、`:408-411` statusBar），demo schema 未声明任何 region，因此默认 `EditorToolboxPanel`（含对齐×6/分布×2/z-order×4/copy/cut/paste/undo/redo/导入导出/删除/成组解组共 24 个按钮，`toolbox/toolbox-panel.tsx:169-216`）与连线拖拽生产接线（`renderer/hooks/use-editor-engine.ts:183` → `connection-wiring.ts:16`）**已经在 demo 页自动生效**。M2/M3 能力不是「未接线」，而是「已随 renderer 默认面露出，但 demo 页没有呈现它们的样例数据、出口与叙事」。
- 真实残余缺口 = ① demo 页缺连线样例数据（无 `scada-pipe-junction` 图元 → 连线拖拽不可触发）、save/export 结果不可见、preview 模式不可达、文案停留在 E5 M1（接线欠账）；② 断开连接工具 / 撤销历史面板 / 图层管理面板三类 UI 在包内**无 UI 实现**（仅程序化 API 或完全缺失）；③ 数据源绑定面板 / 模板库 / 站点管理等产品级大件**无设计无实现**；④ E10 记录的四项 post-mission 可选项维持 demand-gated。
- **R7 状态**（L5.7 特别核对）：primary 档 ①②④ 已由 E9.2 复测数值化达标（`docs/analysis/industrial-hmi-editor/editing-envelope-retest-2026-08-07.md` §2：① 拖拽 best 50.2fps@1k ≥30fps；② per-call max 13.1ms <100ms；④ 内存 50.2MB ≤320MB），**待人工最终确认**（roadmap 头部 line 3 + E10 记录 line 34，AI 不自确认）；**extended ≤10k 档无数值化确认**——复测报告 line 26/53 明确「extended（≤10k）未在本轮升级为正式包络，维持留观察」。
