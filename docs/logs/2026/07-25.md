## Changes

### Gantt bars rendering fix

- **Root cause**: `gantt.tsx` had a redundant `useEffect` (lines 81-87) calling `store.parse()` a third time, duplicating the same work already done in `createInitialStore()`. In React Strict Mode:
  1. `createInitialStore` → `store.parse()` (1st call, 14 tasks)
  2. Effect fires → `store.parse()` (2nd call, 14 tasks, bumps `taskRevision`)
  3. Strict Mode cleanup → `store.destroy()` clears tasks + `parentIndex`
  4. Effects re-fire → 2nd parse skipped by `initCalledRef`
  5. Pending GanttBars re-render (from step 2's `taskRevision++`) executes AFTER `destroy` → reads empty store → 0 bars
- **Fix**: Removed the duplicate effect entirely (lines 79-87 in `gantt.tsx`). `createInitialStore` already calls `parse`. Moved `undoStack.clear()` to the mount effect.
- **Files**: `packages/flux-renderers-scheduling/src/gantt/gantt.tsx`
