# Stripe dashboard 数据面板复刻分析（P7 输入）

> 分析对象：Stripe Dashboard payments 区域（交易列表 / 筛选 chip / 明细 drawer / 图表卡）（开源状态：**闭源，风格等价复刻 + 差异声明**）
> 调研日期：2026-08-29（来源见 §8；官方 docs.stripe.com 四篇全文抓取成功；hex/字号/行高多为风格等价拟定值，已逐项标注考证状态）
> 上游：R1 §4 G-E、C1-3（高密度交易流水表构想）、C2 **G-E（高密度排版）/ G-B3（批量操作栏）——本应用主对照行**；下游：P7a / P7b

## 1. 应用概述

Stripe Dashboard 是金融数据面板的密度与排版标杆：高密度交易表格 + 筛选 chip 条 + 语法搜索 + 状态语义色 pill + 金额等宽排版 + 明细侧栏。对 flux 的价值在 **G-E 高密度排版**（密度档/等宽计数/语义色/chip）的变量级提取，以及"金融表格"这一未验证场景（roadmap 初判：高密度数据页未验证）。

## 2. 设计令牌结构（数据密度与排版令牌提取到变量级）

### 2.1 色彩（考证状态逐行标注）

| 品牌紫（blurple）                       | `#635bff`                                          | 📊 多源一致（Mobbin/colorize.design/designsystems.one）；官方仅文字表述 "slate and blurple" |

| succeeded / pending / failed / refunded | 绿 / 琥珀 / 红 / 灰（Badge 模式：彩底 + 同系深字） | 结构 🌐 可考（官方色彩系统博客 Badge 规则），具体 hex 拟定                                  |

**色彩系统结构（🌐 官方可考，比 hex 更重要）**：每色为统一明度曲线的分级色阶（CIELAB 感知均匀空间）；对比规则内置——小字文本两色间隔 ≥5 档、图标/大字 ≥4 档；白底与任一色最浅档底上默认文字过 WCAG 4.5/3.0；**Badge = 背景 +1 档、文字再 +1 档**（"色阶对"而非单色）。复刻语义状态 pill 必须按色阶对实现。

### 2.2 排版

字体 **Söhne**（Klim Type Foundry 商业授权，`sohne-var`，展示位 weight 300 常见）📊 → 复刻用 `Inter/system-ui` 风格等价并在差异声明注明。字号（拟定）：表格辅助 12 / 表格正文 13 / 正文 14 / 小标题 16 / 页标题 24–28px；Dashboard 整体偏小字号高密度。**金额 = tabular figures（等宽数字）+ 右对齐**——金融表格结构特征，复刻硬约束。

### 2.3 间距/圆角/行密度（拟定档）

4px 间距节奏；圆角 ~4px 📊。行密度三档：默认 ~40px / 紧凑 ~32px / 宽松 ~48px → **G-E 密度档语义字段的参照值**；侧边导航宽 ~240px（拟）。

### 2.4 交互习惯

过渡 ~150ms、行 hover 浅灰高亮、焦点 ring（拟定；对比度保障为 🌐 官方原则）。键盘 `?` 呼出快捷键面板（🌐）；**筛选/搜索状态写入 URL → 可书签/分享**（🌐，结构特征）。

### 2.5 图标

细描边线性 16px 网格 + 卡组织彩色小徽标（拟定；用 lucide 近似）。

## 6. 可复刻边界与差异声明

### 6.1 可复刻

高密度表格结构、筛选 chip 条、日期范围预设档、状态 pill 色阶对模式、金额等宽排版、drawer 明细形态、图表卡 + widget 增删、导航 shell 分组模型。

### 6.2 差异声明（令牌/布局与原版偏离点）

- 令牌偏离：`#635bff`/`#0a2540` 为第三方多源可考值（官方未公开 hex）；页面底/边框/次级文字/行高 px 为风格等价拟定，P7a 落 CSS 前以视觉核对校准；Söhne 商业字体 → Inter/system-ui 栈，**声明非原字体**。
- 布局偏离： Stripe 无批量栏 → 复刻页**不新增**批量栏（与原版结构一致），G-B3 对照行记"参考应用无此件"；密度档位为拟定补充，原版未文档化。
- 交互偏离：语法搜索属自研解析器，复刻降级为"chip 筛选 + keyword 搜索"组合并记录降级；退款/Dispute 等业务操作为静态演示。
- 文案与图标：Stripe logo/词标（Marks Usage Agreement 约束）/插画/产品截图素材全部不使用；导航词/状态词/按钮文案自拟中文等价（结构保留、文案全换）。
