## ④ 高风险逐项复核详情（HIGH 1 条）

### [G5-视角10-01] 会话删除一键直达、无确认且不可逆 — 维持 HIGH

**复核过程**:

1. **Renderer 侧**: 精读 `packages/flux-renderers-ai/src/renderers/ai-conversations.tsx:138-151`。删除按钮为 ghost+sm+`×` 字符（:150），`onClick` 内联构造 `{ type: 'ai:conversation-delete', id: conv.id }` 后**直接** `void props.events.onItemDelete?.(payload, dispatchCtx(payload))`——onClick 与事件派发之间无任何确认层、无中间状态（无 arming/二次点击/弹层）。`disabled` 仅来自 `meta.disabled`（:25）。

3. **严重度标尺比对**: 共享前缀 HIGH = "不可逆破坏性后果、破坏性操作无确认"。本条同时命中两条：不可逆（storage 物理删除）+ 无确认（一键直达）。视角10 基线"行级=ghost+可选确认"针对的是列表行内条目移除；此处删除对象是数据承载实体（整段会话历史），发现对该边界的论证成立。
