3. **DV-OPS-02: Component handle methods untested** — content/diff-view. While `useImperativeHandle` is now wired, no test calls `toggleViewType()` / `expandAll()` / `collapseAll()` and asserts behavior. Schema authors relying on `component:toggleViewType` action have no test protection.

4. **MA4-F01: Validation compile→runtime bypass** — all form renderer packages. No test compiles a form with validation rules, creates runtime, sets bad values, submits, and asserts errors. The form/field renderers have no end-to-end validation test.

5. **MA4-F02: Validation error never tested in DOM** — all form renderer packages. No test renders a form with required field, submits, and asserts error message appears in DOM. The FieldFrame error display path is untested across all renderer packages.

6. **F1: CRUD raw schema read** — data/crud. `crud-renderer.tsx:512` reads `props.schema` at runtime instead of compiled/normalized props. While not currently producing bugs, it violates the compile-once contract and has no regression test to prevent future misuse.

### P2 (Medium risk)

7. **DV-OPS-03: `areHunkPropsEqual` misses `onHunkExpand`** — content/diff-view. Callback reference change won't trigger re-render, causing stale closure bug in hunk expand/collapse.

8. **DV-OPS-04: Ctrl+Arrow global key shortcuts** — content/diff-view. Window-level listener can conflict with other components (e.g., gantt). No test for scope-limited activation.

9. **MA4-F10: validateForm() missing concurrent guard** — form-advanced/composite fields. Race condition when multi-field async validation fires from multiple callers simultaneously.

10. **P0-6: Array-field scope-only Add/Remove untested** — form-advanced. The scope-only write path exists in code but no test verifies Add/Remove works when there's no parent form.

11. **DV-TEST-03: Zero-assertion DiffFileList tests** — content/diff-view. Two tests still assert only `length > 0`, which passes regardless of feature state. False coverage confidence.

12. **MA4-F10: validateForm() concurrent guard** — form-advanced. No protection against concurrent validateForm() calls.

### P3 (Low risk)

13. **DV-DISP-01: Dead `content` param** — content/diff-view. Low risk (dead parameter, no functional impact).

14. **DV-DISP-04: Dead exports** — content/diff-view. Three exported components never imported. Code quality only.

15. **DV-DISP-06: 3-way merge multi-conflict-zone fragility** — content/diff-view. Difficult to trigger; test exists at model level but no integration test.

16. **F7/F8: Silent catch blocks** — mobile/data. Best-effort catches with unused err bindings. No functional impact.

17. **F5: Duplicate copy-to-clipboard** — basic + data. No functional bug, just DRY violation.
