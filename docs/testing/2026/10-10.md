## 36. taskflow 树模式连线"+"按钮相对连线右偏、不在线中心

- **所属组件**: taskflow-designer（Tree tab）/ flow-designer-renderers 树模式 handle 定位
- **问题描述**: 树模式链线上的蓝色"+"添加按钮中心不在竖直连线上，视觉上总是偏右（线贴着按钮左缘）。用户复核 557 树卡重构成果时发现。
- **预期行为**: "+"按钮中心与连线、所在卡片中心三者水平同心
- **发现方式**: 人工测试（用户目检 + 坐标质疑）
- **状态**: 已修复——根因为树手柄双重居中位移（xyflow 基础 `transform: translate(-50%, 6px)` 与 Tailwind `!-translate-x-1/2` 的独立 `translate: -50%` 属性叠加 -12px，手柄中心左偏 6px，边线走手柄中心跟着左偏，而 + 按钮对卡居中）；删除冗余 Tailwind translate 类（render-ports.tsx，TB/LR 同修），提交 a001e1f6e；判别守护 e2e 见 taskflow-designer-ui.spec.ts "Tree chain + button is concentric"（红→绿实测）；详见 docs/bugs/100

## 38. gantt 连线删除 X 钮 hover 反复闪烁、无法点击

- **所属组件**: gantt（flux-renderers-scheduling gantt-links）
- **问题描述**: 鼠标悬停 gantt 连线出现红色 X 删除钮后，按钮反复闪烁（实测 1 秒内 15 次挂载/15 次卸载），无法稳定点击。根因：X 条件渲染在连线中点、位于 10px 命中 polyline 的悬停区内，指针落到 X 上触发 polyline mouseleave → X 卸载 → 指针回到 polyline → 重挂载循环。
- **预期行为**: 指针停在连线或 X 上时 X 保持稳定可点，离开链线区域才消失
- **发现方式**: 人工测试（用户报告）
- **状态**: 已修复——hover enter/leave 上移到链线 `<g>` 组（gantt-links.tsx，指针在 polyline 与 X 间移动不再清状态），提交 4e4fde426；判别守护 e2e 见 gantt-bars-and-links.spec.ts "link delete button is stable"（预修复 stash 对照红 15/15 振荡 → 修复后绿）；详见 docs/bugs/101
