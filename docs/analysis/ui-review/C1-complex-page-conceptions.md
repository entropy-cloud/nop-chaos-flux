# C1 — 复杂页面构想清单与能力压力预判

> Last Updated: 2026-08-19（基点 9d8a3fd96 + R1 同批）
> Mission: `missions/ui-review.json` · Roadmap: `docs/backlog/ui-review-roadmap.md`（C1 产出文档）
> 输入：R0 §4 复杂度分级与去重基线、R1 §4 差距清单（G-A~G-I）、sundial 分析 §3 复杂度口径、plan 460 B8 runtime 语义发现

## 0. 构想原则

与既有 19 页去重（R0 §4 去重基线：企业向 14 页覆盖 ★★~★★★ 表格/表单/主从/向导族，Sundial 5 页覆盖 ★★★★+ 表面嵌套/状态机）。本批 10 页瞄准**未覆盖簇**：命令面板、多视图数据库、高密度金融表、看板拖拽重排、预约流程、审批流程图中心、图表门户、移动 shell、三栏 inspector 工作台、结果页终态。每页给出：复杂度 ★（sundial §3 口径）／所需 flux 原语映射／预测缺口（显式对照 G3/G5 与 R1 G-A~G-I）。

## 3. 与 P 系列复刻的衔接

P2（AntD Pro 模板族）↛ C1-10；P3（Cal.com）↛ C1-6；P4（Linear）↛ C1-2 + G-B 全家；P5（Notion）↛ C1-4；P6（Airtable）↛ C1-3/4 的 G-D 压测；P7（Stripe）↛ C1-3 的 G-E 压测。C1-1/7/8/9 四页不在 P 系列名单内，作为**构想库存**保留（若 P 系列复刻回写证实同类缺口，C2 升级其优先级；不单独开线，避免与 P 系列重复劳动）。

## 4. 复测口径

构想本身无可执行复测；压力预判的验证责任由各 Pi-b 的"预测缺口 vs 实测缺口"对照承载（roadmap Cross-Cutting §5 回写义务）。
