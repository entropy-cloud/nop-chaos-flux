## hucre 电子表格引擎调研与 report designer 对比报告

- 起因：评估外部 Excel 编辑控件 hucre（github.com/productdevbook/hucre）与本项目 report designer 的关系。
- 已克隆源码到 `~/sources/hucre`（v1.1.0，MIT，commit 2026-09-01）。
- 关键结论：hucre 是 **headless 电子表格文件引擎**（读写 XLSX/CSV/ODS/JSON/XML，零依赖，无任何 UI、不求值公式），不是 UI 编辑控件；与本侧 spreadsheet + report designer（纯 JSON 文档、DOM 网格 UI、无二进制格式能力）**正交互补**。
- 互补点：hucre 恰好填 report designer 显式留白的 `TemplateCodecAdapter`（现仅 `createUnsupportedTemplateCodecAdapter` 占位）与二进制格式导入导出；集成需新写"行数组稠密模型 ↔ A1 稀疏文档模型"映射层。
- 风险：hucre 幼年项目（npm 2026-03 首发，13 版本/5.5 月）、engines node>=24、readXlsx ~39KB gz；建议锁版本 + codec 包内薄封装。
- 产出：`docs/analysis/2026-09-12-hucre-vs-report-designer-comparison.md`。
- 性质：纯调研 + 文档，无代码变更；typecheck/build/test 不适用。
