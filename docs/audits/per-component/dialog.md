## 发现清单

- [P1-1] 真机 modal dialog 焦点逃逸（a11y-focus-trap 失败路径）：Base UI 1.3.0 focus guard 回绕在真实浏览器失效——从 close 按钮 Tab 后焦点经 after-guard 落到 `document.body` 与页面 chrome（probe 复现：TAB 3 guard → TAB 4 BODY → TAB 5 页面按钮），两拍后绕回 dialog。app root 有 aria-hidden（AT 隐藏生效）但原生 Tab 序不受 aria-hidden 约束。根因在 ui 公共层（`@nop-chaos/ui` Dialog/Drawer + Base UI guard 机制）→ 状态: fixed（ui 层确定性 wrap：`wrap-surface-tab-focus.ts`，Dialog/Drawer popup 各挂 onKeyDown，Tab 循环在 popup 首尾 wrap，焦点不再进入 guard 循环；ui 单测 + e2e 全绿）
- [P2-1] `DialogSchema.draggable`/`allowFullscreen`（`schemas.ts:74-77`）在 definition fields 缺失 → closed model strict 下 unknown-property error（`shape-validation-node-fields.ts:239-268`）；design.md §5.1 声明 typecheck-only，类型与定义不一致 → 状态: fixed
