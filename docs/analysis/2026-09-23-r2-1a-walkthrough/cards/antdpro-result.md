### [R2-1a-E4-01] 结果图形（勾图标）贴绿带左缘，与整页居中版式冲突

- **页面/路由**: `#/complex-pages/antdpro-result`
- **主题/视口/状态**: light / 1280×800 / 默认
- **截图**: `_tmp/visual-inspection-2026-09-23/r2-1a/antdpro-result/antdpro-result-default-light.png`
- **目视描述**: 淡绿结果带横贯卡片（590px 居中），48px 勾图标孤零零贴在带内左侧，而标题/描述/按钮全部居中——视觉重心左偏。
- **程序化证据**:
  - 探针: rect 采样（`antdpro-darkfix-probe.mjs` → `resultAlign`）
  - 输出: 卡片 cx=760、绿带 cx=760（w=590）、标题 cx=760，**svg cx=505**——图标中心偏离带中心 255px，紧贴带左缘（svg.x=481 vs band.x=465，仅 16px 内边距）
- **对照基准**: 检查提示词 E4（对齐）/E2（视觉层级与重要性一致）；AntD Pro result 原版成功插图为居中构图
- **严重程度**: P3（不影响任务，观感失衡明显）
- **用户影响**: 成功页是流程终点的高情绪价值页面，构图失衡削弱"完成"的正反馈。
- **修复方向**: antdpro-result schema 将勾图标与文案改为纵向居中堆叠（图标 `mx-auto` 或容器 `items-center`），或把图形带改为图标+文案的左对齐组合并让整卡文字左对齐——二选一，当前"带居中+图标左贴"最差。
- **归族**: local → R2-4 批
- **复核状态**: 未复核
