## 发现清单

- [P1-1] **`getSelectedAxisInfo` count 返回 span 而非实际选中数（MA5 P3-12 确认）**（`spreadsheet-grid/constants.ts:105-123` `count: end - start + 1`）——多选（shift-click 累积 rows 数组 [2,5]，selection-handlers.ts:69-84）时 count=4 而非 2 → 消费点：`spreadsheet-grid.tsx:75-76`（canResize 判定，单行不受影响）+ **`use-context-menu-actions.ts:104/137/168`（插入/删除行/列 count 传 span → 删除未选中行/列的数据丢失风险）** → 状态: **fixed**（`constants.ts:105-123` count 改 `values.length`；复现测试 `spreadsheet-grid/axis-info.test.ts`，bug note 108，plan Phase 4）
- [P3-1] 选区操作日志硬编码英文（use-selection.ts:242-367 系列，默认宿主无 onLog 消费非用户可见）→ 状态: 卡内记录（i18n 化归 DR 候选）
- [P3-2] `commitEditingCell`/`getSelectedRange` 硬编码 100×26 网格边界（`use-selection.ts:68-69` totalRows/totalCols + :110 越界检查；`use-fill-handle.ts:83/:104` 同款 26/100）与宿主动态维度不一致（default-page-body 大文档 rows>100 时 101+ 行编辑提交被丢弃）→ 状态: 卡内记录（边界能力缺口；当前默认宿主 100×26 内无影响）
- [P3-3] `ss-selection-border` 死 CSS 类（canvas-styles.css:699 无渲染方）→ 状态: 卡内记录
