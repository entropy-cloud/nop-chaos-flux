## Purpose

对 designer 包簇（flow-designer/report-designer/spreadsheet/word-editor）执行复杂交互显示与可操作性审计 + 对 basic-renderers（basic/form/form-advanced/data）和 content 包簇执行 UX 设计合规性审计，产出 P0/P1 发现并更新 arm-index。

## Current Baseline

- MA1–MA4 所有审计阶段已完成，arm-index 已建立完成（全维度）。
- designer 包簇（170 文件，S 级）包含 flow-designer、report-designer、spreadsheet、word-editor，此前已完成 MA1.4（结构/样式）、MA3.3（代码质量）、MA4.3（测试覆盖）审计，定位于复杂交互组件。
- basic-renderers（261 文件，S 级）和 content（85 文件，B 级）此前已完成 MA1.3（结构）、MA2.3（分发/Action）、MA3.2（代码质量）、MA4.2（测试覆盖）审计，但未接受过 UX 维度的系统审查。
- `docs/analysis/` 中可能已有零散的 UX 审查报告，需快速扫标题建立去重基线。
- `pnpm typecheck`/`build`/`test` 绿色基线已确认，存在 1 个 playground flaky 性能测试。

## Goals

- 对 designer 包簇执行复杂交互显示与可操作性审计，按 `complex-component-display-operability-audit-prompt.md` 方法论执行。
- 对 basic-renderers + content 包簇执行 UX 设计合规性审查，按 `ux-design-pattern-audit-prompt.md` 方法论 + `check:audit-missing-renderer-markers` 执行。
- 对每项发现给出严重度（P0/P1/P2/P3）、类别、位置、现状、最小补强建议。
- 产出两份审计报告并更新 arm-index。
- 发现的 P0/P1 项在 MR3 fix plan 中处理，本 plan 不做代码修复。

## Non-Goals

- 不直接修改生产代码或测试代码。
- 不涉及 core/runtime 包簇、mobile 包簇、AI 包簇、scheduling 包簇的 UX 审计。
- 不包含 P1 修复执行。
- 不重复 deep-audit 已覆盖的架构契约维度（维度 09-12，如 RendererComponentProps 遵循、marker class 纯标记、BEM 残留等）。

## Scope

### In Scope

- **Workstream 1 — Designer 可操作性**: flow-designer-core/renderers、report-designer-core/renderers、spreadsheet-renderers、word-editor-core/renderers
- **Workstream 2 — Basic+Content UX**: flux-renderers-basic、flux-renderers-form、flux-renderers-form-advanced、flux-renderers-data、flux-renderers-content

### Out Of Scope

- core/runtime 包簇
- mobile、AI、scheduling 包簇
- designer/office 包簇的代码质量或测试覆盖（已由 MA3.3/MA4.3 覆盖）
- 生产代码或测试代码的修改
